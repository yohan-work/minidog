# Code of conduct

minidog follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be kind and assume good intent. Critique code, not people.
- No harassment, insults, or personal or political attacks, in any form.
- Respect people's time: be clear about what you need, and accept a "no" with grace.

This applies in issues, pull requests, discussions and anywhere you represent the project.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer ([@yohan-work](https://github.com/yohan-work)) privately through GitHub. For anything sensitive, use a private security advisory on this repository, which only the maintainer can read. Reports are handled confidentially. Consequences range from a private warning to a permanent ban, as described in the Contributor Covenant's enforcement guidelines.
